# 💻 CV Interactivo Online

## 📌 Descripción

Este proyecto consiste en un CV interactivo desarrollado utilizando HTML, CSS y JavaScript.

El objetivo es presentar información personal y profesional de una manera organizada, visual e interactiva.

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code
