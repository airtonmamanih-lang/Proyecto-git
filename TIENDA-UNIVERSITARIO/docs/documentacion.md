# TIENDA UNIVERSITARIO

## Tienda virtual de artículos deportivos de Universitario de Deportes

---

## 1. Descripción del proyecto

Tienda Universitario es una propuesta de comercio electrónico orientada a la venta de artículos deportivos y productos relacionados con Universitario de Deportes.

El proyecto busca representar una experiencia moderna de compra online, permitiendo a los usuarios explorar productos, consultar información, agregar artículos al carrito, guardar favoritos y completar un proceso de compra simulado.

---

## 2. Objetivos

### Objetivo general

Desarrollar una tienda virtual moderna, responsive e intuitiva para la comercialización de artículos deportivos relacionados con Universitario de Deportes.

### Objetivos específicos

- Mostrar productos organizados por categorías.
- Permitir consultar información detallada de cada producto.
- Implementar búsqueda y filtrado.
- Implementar carrito de compras.
- Implementar sistema de favoritos.
- Crear un proceso de checkout.
- Mostrar promociones.
- Crear una interfaz adaptable a dispositivos móviles.
- Separar datos, estructura, estilos y lógica.
